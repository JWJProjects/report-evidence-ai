# Archetype D — 公共明文 Civic Plain

**適用**：無障礙稽核、民眾端服務、申辦流程、法規檢核清單、任何「介面本身要示範好可及性」的案子。
**目前指派**：`accessible-service-qa`（可達）

## 設計立場
這類工具的可信度來自「它自己就做得到」。介面走政府數位服務的克制路線（參考 GOV.UK Design System、美國 USWDS 的原則，而非外觀照抄）：大字、高對比、單欄、平鋪直敘、沒有裝飾。風格感來自排版紀律，不是色塊與漸層。

## 版面骨架
- **單欄**，主內容最大寬 960px，左對齊（不是置中卡片）。
- 頁首：白底＋底部 6px 實色粗線（強調色），服務名稱為純文字。不用圓角 logo 方塊、不用深色 hero。
- 合成資料／展示限制：頁首下方 **階段橫幅**（`示範` 標籤＋一句說明）。
- 主流程以 **步驟導覽**（1 初測 → 2 整改 → 3 複測 → 4 人工覆核 → 5 匯出證據）組織，每步一個區塊、標題清楚。
- 檢查結果用 **摘要清單（summary list）**：左欄項目、中欄狀態、右欄動作連結。
- 細節用 `<details>` 展開，而非分頁或彈窗。
- 數字統計以一句話呈現（「初測發現 4 項，目前 0 項」），不做大數字卡。

## 色彩
- 背景 `#FFFFFF`；文字 `#0B0C0C`；次要文字 `#484949`；分隔線 `#B1B4B6`
- 連結 `#1D4ED8`（**一律底線**），已造訪 `#5B21B6`
- 強調（頁首粗線、主要按鈕）：`#1D4ED8`
- **焦點樣式（簽名）**：背景 `#FFDD00`＋文字黑＋底部 4px 黑線，所有可聚焦元件一致。
- 錯誤 `#B42318`；成功 `#1E6B3A`；狀態標籤為實色底白字，且含文字。
- 禁用：漸層、紋理、半透明疊色、墨綠 hero。

## 字體
- 無襯線堆疊，**基準 18px**，行高 1.6；H1 32–40px／700，H2 24px；不做負字距。
- 不使用 mono 裝飾；只有程式碼與 CSS 選擇器用等寬。

## 密度、形狀
- 寬鬆。圓角 **0**（按鈕可 0–2px）。按鈕最小高 44px，主要按鈕底部有 2px 深色陰影線。
- 無卡片陰影；用標題、間距與分隔線分區。

## 元件語彙
階段橫幅、步驟導覽、摘要清單、狀態標籤、錯誤摘要（頁頂列出所有錯誤並連到欄位）、提示文字、`<details>`、檢核清單（核取＋人工結果下拉）。

## 互動
- 頁面錯誤時，焦點移到錯誤摘要。
- 狀態變更以 `aria-live="polite"` 宣告。
- 無動畫（除焦點即時變化）。

## 簽名元素
黃底焦點樣式＋頁首粗色線＋摘要清單。

## Dogfooding（必做）
用本工具自己的四項規則掃自己的介面，結果必須為 0；在 README 註明。

## 手機（390px）
本來就是單欄；摘要清單在窄版改為上下排列（項目／狀態／動作）。

## 文案語氣
白話、短句、以使用者動作開頭：「選擇要檢查的頁面」「修正後，重新檢查」。避免術語，必要時第一次出現加說明。

## 驗收補充
- 所有文字對比 ≥ 7:1（AAA）為目標，至少 4.5:1。
- 200% 縮放無內容遺失。
