# Archetype B — 卷宗 Case File

**適用**：成果填報、送審／退回／核准流程、公文、佐證查核、原文回查、公開版發布。
**目前指派**：`report-evidence-ai`（案跡）

## 設計立場
使用者是承辦與審核人，工作是「讀文件、下判斷、留紀錄」。介面應該像一份正在流轉的卷宗：紙本、批註、用印、簽核軌跡。閱讀舒適與可追溯性優先，資料視覺化其次。

## 版面骨架
- **三欄閱讀式**：
  1. 左：**卷宗目錄**（像檔案夾分頁標籤，垂直排列：填報單／佐證／來源文件／簽核紀錄）。
  2. 中：**文件主體**，置中、最大寬 72ch，呈現「一頁紙」的樣子（白紙、淡邊、微陰影、上方有文號列）。
  3. 右：**邊註欄**：審核意見、退回理由以「頁邊批註」呈現，對齊到相關欄位。
- 流程狀態不是 stepper 卡片，而是頁首的 **公文流程列**：`草稿 → 審查中 → 已核准 → 已發布`，以細線連接、目前位置以印章標記。
- 頁首：淺色、細，像文件抬頭（機關名＋案號＋版本），不使用深色頂欄。
- 公開版預覽：以「同一份文件的另一個版本」並排呈現，非公開欄位顯示為遮蔽條。

## 色彩
- 背景（桌面）：`#F3EFE6`；紙面：`#FFFDF8`；分隔線：`#D9D0BE`
- 文字：`#24211C`，次要 `#5E574B`
- **朱印紅**（只用於印章、退回、必填標記）：`#A8261B`
- 核准藍（官印／已核准）：`#22408A`
- 螢光筆（原文命中高亮）：`#FFF0A0` 底＋`#24211C` 字
- 狀態色僅出現在印章與流程列，不鋪大面積。
- 禁用：深色側欄、薄荷綠、青綠。

## 字體
- 文件標題與文件內文：**明體堆疊**（見 org-baseline），內文 16px／行高 1.8。
- 介面控制項、表單標籤：無襯線 14px。
- 印章文字：楷體堆疊（少量）。
- 文號、版本、日期：等寬，但不加大寫字距。

## 密度、形狀
- 寬鬆，段距大。紙面圓角 **2px**；按鈕 3px。
- 陰影模擬疊紙：`0 1px 0 #D9D0BE, 0 6px 16px rgb(60 45 20 / .08)`。

## 元件語彙
印章（雙框、旋轉 -4°，文字＋日期）、頁邊批註（左側細色條＋署名＋時間）、引文區塊（含文件名、段落、版本、日期）、遮蔽條（公開版隱藏欄位）、並列比對（日期衝突時兩段原文左右並排）、簽核紀錄（直式時間軸，像公文簽核單格線表）。

## 互動
- 退回時，理由輸入框以批註形式出現在對應欄位旁。
- 點引用 → 文件主體捲到原文並以螢光筆標示。
- 用印動畫：印章 120ms 縮放落下（reduced-motion 時直接出現）。

## 簽名元素
印章＋頁邊批註。

## 手機（390px）
單欄：目錄收成頂部下拉；邊註改為欄位下方的內嵌批註；流程列改為「目前狀態印章＋下一步按鈕」。

## 文案語氣
公文體但白話：「請補正：實施場次與附件不符」「本段原文載明…」。不寫行銷口吻。

## 驗收補充
- 印章與狀態一定含文字，不只顏色。
- 文件內文行長 ≤ 72ch，行高 ≥ 1.7。
